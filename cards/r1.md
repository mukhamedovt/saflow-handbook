# Проверить фрагмент

Откройте профиль «1С», если смотрите модуль конфигурации. Иначе оставьте «Любой код». Отметьте то, что уже нашли глазами. Вставьте критерий и фрагмент модуля. Скопируйте запрос: модель перепроверит галочки и не будет переписывать код.

Фрагмент должен быть коротким. Одна процедура проведения, один метод HTTP-сервиса, один общий модуль. Вся конфигурация в запрос не помещается и прячет дыру.

Если критерия ещё нет, проверка рано. Сначала карточка истории.
