# saflow

Настольный справочник системного анализа. Открываете одну страницу, выбираете ситуацию, читаете, что уже должно быть на столе, и копируете промпт в новый диалог.

Правила взяты из статьи [«Системный анализ в эпоху LLM»](https://habr.com/ru/articles/1098788/). Домен в страницу не зашит: в промпт вы подставляете свой проект и слова заказчика.

## Открыть

Дважды щёлкните `Запустить справочник.command` в этой папке. Откроется браузер со справочником.

То же самое из терминала, из этой папки:

```bash
python3 saflow.py
```

Без команды скрипт больше не требует аргументов: он открывает страницу. Адрес в интернете, если папки под рукой нет: https://mukhamedovt.github.io/saflow-handbook/

Слева — ситуация, в которой вы сейчас. Справа — карточка этого шага и готовый промпт. Кнопка «Скопировать промпт» забирает системные правила и пользовательский блок с местами, куда вставить страницу проекта, бриф и прошлые артефакты. «Скопировать только правила» забирает системный промпт.

Поиск над списком ищет по названию ситуации и тексту карточки. Ссылка с решёткой открывает шаг сразу, например `index.html#05`.

## Как работать с карточкой

1. Выберите ситуацию, а не все шаги подряд.
2. Прочитайте, кого спросить и что модели нельзя делать.
3. Скопируйте промпт в новый диалог. Прошлый чат не продолжайте.
4. Подставьте страницу проекта и файлы, которые промпт называет. Чего у вас нет, не дописывайте правдоподобным правилом: оставьте это открытым вопросом с адресатом.
5. Примите ответ только если он проходит раздел «Принять».

Шаг, которого в системе нет, не изображают. В промпте на его месте пишут причину: нет своей базы, нет HTTP, нет шины.

## Что лежит в папке

| Файл | Зачем |
| --- | --- |
| `index.html` | Страница, которую открывают |
| `cards/` | Текст карточек, источник страницы |
| `prompts/` | Системные промпты шагов |
| `handbook.template.html` | Оболочка страницы |
| `build_handbook.py` | Собирает `index.html` заново после правки карточки или промпта |
| `saflow.py` | Та же цепочка в терминале: `card`, `prompt`, `validate` |

После правки карточки или промпта:

```bash
python3 build_handbook.py
```

Терминал необязателен. Если он нужен:

```bash
python3 saflow.py card 02
python3 saflow.py init payments-retry --title "Повтор платежа"
python3 saflow.py prompt payments-retry 01
```

Фичи из терминала складываются в `saflow-work/` рядом с местом запуска и в репозиторий не входят.
